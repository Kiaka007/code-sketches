# code-sketches

Small tools and sketches made in code — things worth keeping and showing, not full projects.

Each sketch lives in its own dated subfolder: `YYYY-MM-topic/`. A sketch may graduate into its own standalone repo if it outgrows this space; until then, it lives here.

## Sketches

| Sketch | What it is |
|---|---|
| [`2026-06-gradient-widget/`](./2026-06-gradient-widget/) | Interactive Jupyter widget that generates a smooth HSL gradient grid from four corner anchor points, with click-to-copy HSL values per cell |
| [`2026-09-spider-graph-attribution/`](./2026-09-spider-graph-attribution/) | Spider-graph interface for a small from-scratch GPT — drag a per-source dial to blend between training sources and feel how "alpha" works; built on Andrew Trask's abcGPT |
